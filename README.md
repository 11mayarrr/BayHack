# لوحة أوقات التبرع – إحسان

لوحة تحليلات لفريق إحسان توضّح متى يتبرع الناس أكثر: الساعات، أيام الأسبوع، أيام الرواتب، والمواسم الهجرية، مع ترتيب أفضل الفترات لتجربة الحملات.

- الملف: `index.html` (ملف واحد مستقل، البيانات مضمّنة داخله).
- افتحه مباشرة في المتصفح، أو فعّل GitHub Pages:
  Settings → Pages → Source: `Deploy from a branch` → اختر الفرع والمجلد `/ (root)`.

مصدر البيانات: `ehsan_rows_2021-04_2023-06.csv` بعد استبعاد الاستقطاعات الآلية والنسخ المكررة، ونتائج نموذج بواسون من دفتر كولاب.
